介绍 ​

Workflow 是面向 Vue 3 的工作流设计器。通过 @bubblesjs/workflow-vue-core 的 Designer 组件，你可以在应用中编排审批、填写、抄送、条件分支和循环流程。

流程结构保存在 nodes 数组中。设计器负责添加与删除节点、组织分支和循环、计算布局与连线；使用方负责业务表单、权限、数据持久化，以及与工作流引擎的对接。

能做什么 ​

  • 可视化编排：通过添加入口插入业务节点，自动维护条件分支、循环与退出结构。
  • 数据驱动：使用 v-model:nodes 接收完整节点数组，配置变更立即反映到画布。
  • 业务配置：监听 node-click，在自己的抽屉、弹窗或侧栏中编辑 data.config。
  • 只读展示：设置 readonly 隐藏编辑入口并禁用节点点击，保留画布平移与缩放。
  • TypeScript 支持：通过 WorkflowNode<TConfig> 为业务数据声明类型。
  • 保存与恢复：序列化节点数组保存草稿，恢复数据后继续编辑。

从数据到画布 ​

text
你的应用                      Designer
nodes / data.config  ──────→  自动布局与连线
                     ←──────  添加、删除、增加条件
业务配置表单         ←──────  node-click { id, type }

每个节点拥有唯一 id。同层节点的数组顺序表示执行顺序，parentNode 表示节点归属。无需存储连线，也无需手动维护坐标。

当前范围 ​

当前公开包版本为 0.1.0，基于 Vue 3 和 Vue Flow。画布采用自动布局，支持只读展示，未开放拖拽节点、自定义连线和自定义节点插槽等配置；公开接口见 Designer API。

审批规则、表达式求值、人员选择与实际流程执行由业务系统实现。画布展示条件与循环结构，不会执行这些业务规则。
