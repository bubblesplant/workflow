常见问题 ​

画布没有显示 ​

先检查是否导入 @bubblesjs/workflow-vue-core/style.css，以及设计器的父容器是否有明确高度。Designer 使用 height: 100%，如果父容器高度为零，画布也会不可见。

css
.workflow-container {
  height: 640px;
}

同时确认绑定了 v-model:nodes，并用 createDefaultNodes() 初始化。一个页面存在多个设计器时，应为每个实例设置不同的 id。

为什么没有 node-click 事件 ​

开始、结束和添加入口不触发业务节点点击事件。只读模式也不会触发该事件。编辑模式下，点击审批、填写、抄送、条件、分支或循环节点，再通过事件 ID 从 nodes 中读取当前节点。

能手动拖动节点或修改连线吗 ​

当前设计器使用自动布局，关闭节点拖拽、手动连线和连线更新。数组顺序和 parentNode 决定结构，不需要手动设置 position。当前公开 API 未提供开启这些操作的选项。

如何设置只读模式 ​

为 Designer 设置 readonly，默认值为 false：

vue
<Designer id="workflow-preview" :nodes="nodes" readonly />

只读时隐藏添加节点、增加分支和删除入口，禁用鼠标与键盘触发的节点点击，不触发 node-click 或 update:nodes，保留画布平移与缩放。

deletable: false 仅约束单独删除；需要整体只读时，请使用 readonly。

为什么不能删除“其他”条件 ​

“其他”是条件组的兜底路径，不允许单独删除。每组至少保留两条条件；普通条件只有在总数超过两条时才能删除。需要移除整组时，删除条件分支容器。

修改条件 label 后标题没有变化 ​

条件卡片的标题由 conditionIndex 和 isDefaultCondition 决定，固定展示“条件规则 N”或“其他”。条件表达式应保存在 data.config，通过自己的业务表单编辑。

如何添加退出循环 ​

将鼠标移到循环内部的添加入口，菜单中才会出现“退出循环”。它会退出最近的一层循环；循环内的条件路径也支持退出。

是否提供流程执行能力 ​

组件负责可视化编排，不执行审批、表达式或循环。保存或发布前，需要在业务侧校验配置并转换为目标引擎的数据格式。

如何用于 SSR 项目 ​

设计器依赖浏览器画布环境，建议仅在客户端加载。在 VitePress 中使用 <ClientOnly> 并通过 defineAsyncComponent 动态导入示例；其他 SSR 框架使用对应的客户端组件机制。示例见交互示例。

docs 能否独立构建 ​

可以。运行 pnpm docs:build 即可，文档通过源码别名加载本地组件，用于验证当前源码。发布后的外部项目按包的 exports 引用构建产物。文档构建版本固定为 VitePress 2.0.0-alpha.21。
