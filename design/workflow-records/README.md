# 流程记录与流程图 UI 原型

本目录提供一份独立的静态可交互 UI 原型，用于评审流程记录、运行态流程图与处理详情的展示方式。页面使用模拟数据，不连接后端，也不执行工作流引擎。

## 布局与交互

- **左栏：流程记录。** 按主题或编号搜索，按运行状态筛选；点击记录后，同步更新流程图、实例摘要和处理详情。
- **中栏：运行态流程图。** 展示实际流转路径、条件分支和节点状态；支持选择节点、缩放、适应画布与定位当前节点。
- **右栏：节点处理详情。** 展示处理人、到达时间、停留时长、结果和审批意见，并以时间线呈现处理历史。

“流转记录”独立设计为“当前待办摘要 + 审批记录表”：顶部集中展示当前环节、处理人与等待时长，下方按审批环节、处理人、处理结果、意见 / 说明、处理时间五列排列历史记录。审批意见占据主要空间，表格使用浅灰表头与横向分隔线，状态以小标签表达。支持按记录类型筛选、切换时间排序和导出 CSV。窄屏下转换为平整列表。

通过 `index.html?preview=history#history` 可单独预览流转记录组件；`index.html#history` 保留完整页面上下文。本次调整仅涉及流转记录，既有流程图保持原样。

宽屏下三栏同时展示，流程图占据主要空间。窄屏下记录与详情按需展开，优先保留画布的可读宽度；页面操作区可换行，画布可独立缩放与滚动。

## 状态表达

节点类型颜色与现有引擎一致：审批使用 `#5c88ee → #4269d4` 蓝色渐变，抄送使用 `#e77b9a → #cf5d86` 粉色渐变。白色画布、白色内容区、圆角与轻阴影也保持一致。

节点类型与运行状态分开表达：完成绿 `#27976d`、拒绝红 `#cb5757` 用于结果标签；当前节点使用蓝色描边；未经过的条件分支降低对比度。状态同时使用文字和图标，审批通过或拒绝时仍保留蓝色标题栏。运行查看界面不展示搭建态的添加和删除入口。

## 后续接入数据

| 字段                | 用途                                                         |
| ------------------- | ------------------------------------------------------------ |
| `instanceId`        | 实例唯一编号，关联流程记录、业务单据与历史                   |
| `definitionVersion` | 实例实际使用的流程定义版本，避免用最新定义替代历史快照       |
| `currentNode`       | 当前运行节点；并行审批时应支持多个节点                       |
| `nodes` 的运行状态  | 每个节点的状态、处理人、进入与结束时间，以及实际经过的分支   |
| `history`           | 按时间记录发起、通过、拒绝、转交、加签、撤回等事件及处理意见 |

实际接入时还可补充业务标题、发起人、发起时间、流程状态与业务表单摘要。

## 原型边界

搜索、筛选、排序、选中记录和查看节点等操作仅改变当前原型的展示状态，导出功能下载当前实例的模拟流转记录。示例中的审批结果均为模拟内容，不代表真实审批行为；页面不会提交审批、更新权限、保存运行状态或驱动引擎。真实业务需由后端鉴权、持久化记录并执行状态流转后，再向界面返回结果。
