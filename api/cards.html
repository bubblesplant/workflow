节点卡片 ​

StartCard、EndCard 和 CommonCard 可作为独立展示组件使用。它们不包含流程编排能力，也不会自动成为 Designer 的自定义节点。

ts
import { StartCard, EndCard, CommonCard } from "@bubblesjs/workflow-vue-core";
import "@bubblesjs/workflow-vue-core/style.css";

StartCard / EndCard ​

属性类型默认值说明
labelstring发起 / 结束默认插槽为空时展示的文本
插槽说明
default自定义正文
icon替换默认图标

两者的固定尺寸为 104 × 40px。

vue
<StartCard label="开始申请" />
<EndCard>流程完成</EndCard>

CommonCard ​

Props ​

属性类型默认值说明
titlestring—卡片标题
descriptionstring""默认正文及提示文本
colorstring#5075dc标题背景，可传入 CSS 渐变
deletablebooleantrue是否提供删除入口
showArrowbooleantrue是否展示正文右侧箭头
readonlybooleanfalse只读展示，隐藏删除和箭头，禁用点击及选中状态更新
selectedbooleanfalse通过 v-model:selected 同步选中状态

Events ​

事件参数说明
clickMouseEvent点击正文按钮，同时更新选中状态为 true
deleteMouseEvent删除确认框中选择“删除”后触发
update:selectedboolean点击卡片或点击卡片外部导致状态变化

卡片不会自行从数据中移除；业务侧需在 delete 事件中处理删除。

设置 readonly 后不会触发 click、delete 或 update:selected，也不会显示选中样式。

Slots ​

插槽说明
icon标题左侧图标
title替换标题内容
default替换正文，默认使用 description

固定尺寸为 360 × 124px。长正文以单行省略，提示文本使用 description。

vue
<template>
  <CommonCard
    v-model:selected="selected"
    title="主管审批"
    description="由直属主管审批"
    :deletable="false"
    @click="openSettings"
  />
</template>

<script setup lang="ts">
import { ref } from "vue";
import { CommonCard } from "@bubblesjs/workflow-vue-core";
import "@bubblesjs/workflow-vue-core/style.css";

const selected = ref(false);

  // 打开业务配置表单。
}
</script>
